# Prompt Examples

This directory is reserved for prompt workflow examples that can be inspected outside the Rivya product UI.

Useful Rivya entry points:

- Prompt templates: https://rivya.ai/chat/prompt
- Image workflows: https://rivya.ai/image
- Video workflows: https://rivya.ai/video
- Audio workflows: https://rivya.ai/audio
- Chat workflows: https://rivya.ai/chat

Prompt examples should stay reusable, avoid protected IP or private customer data, and link back to maintained Rivya pages when the product page is the better source of truth.
