## Example Workflows

### Product launch creative brief

Use when a team needs aligned image, video, audio, and copy directions for a launch.

```text
Create a launch-ready creative brief for a new product page.
Include:
- the target audience
- the hero visual direction
- a short video concept
- supporting ad copy angles
- review risks and missing inputs

Keep brand names, claims, product details, and visual references editable.
Avoid unsupported performance claims, protected characters, celebrity likenesses, and fixed logos.
```

Suggested Rivya paths:

- https://rivya.ai/image
- https://rivya.ai/video
- https://rivya.ai/audio
- https://rivya.ai/chat

### Social content response plan

Use when a community or marketing team needs consistent replies and escalation notes.

```text
Draft calm, policy-safe replies to a set of social comments.
Return:
- objective
- known context
- recommended reply options
- escalation risks
- missing information

Mark assumptions instead of inventing facts.
```

Suggested Rivya paths:

- https://rivya.ai/chat/prompt
- https://rivya.ai/tools

### Developer integration planning

Use when a developer wants to plan an API integration before writing code.

```text
Plan a Rivya API integration for a product workflow.
Include:
- required model capability
- input and output shape
- whether Files API is needed
- idempotency and retry notes
- credit and error handling checks
- links to relevant docs
```

Suggested Rivya paths:

- https://rivya.ai/developers
- https://rivya.ai/docs/api
- https://rivya.ai/docs/api-model-reference

## Rules For Prompt Examples

- Keep prompts reusable and editable.
- Avoid protected IP, celebrity likenesses, private customer data, and unsupported claims.
- Link back to maintained Rivya pages when the product page is the better source of truth.
