# Rivya Public

Public examples, prompt workflow notes, and integration resources for [Rivya AI](https://rivya.ai).

Rivya AI is a multimodal AI workspace for image, video, audio, and chat workflows. This repository gives developers, operators, and creative teams a lightweight public reference for the same surfaces that are maintained on the Rivya website: API docs, model references, prompt workflows, and product entry points.

## Start With Rivya

- Website: https://rivya.ai
- Developers: https://rivya.ai/developers
- API docs: https://rivya.ai/docs/api
- API quickstart: https://rivya.ai/docs/api-quickstart
- API model reference: https://rivya.ai/docs/api-model-reference
- AI models: https://rivya.ai/ai-models
- Tools: https://rivya.ai/tools
- Prompt library guide: https://rivya.ai/docs/prompt-library-and-showcase

## What This Repository Is For

Use this repository when you need a public, inspectable reference that points back to the maintained Rivya product pages.

- API integration examples for image, video, audio, and chat workflows
- Prompt workflow examples for creative, marketing, product, and developer tasks
- Public notes that explain how to choose the right Rivya entry point
- Changelog entries for public examples and repository structure

The canonical product and API documentation remains on [rivya.ai](https://rivya.ai). This repository should stay small, readable, and safe to link from external profiles.

## Safety Boundaries

This repository does not contain private application code, private credentials, production configuration, customer data, or internal provider routing. Example snippets should use placeholders for API keys and should link to the maintained Rivya docs when the live product page is the better source of truth.

## Support

For account, billing, product, or security questions, use the official Rivya website and support channels instead of opening issues in this repository.
