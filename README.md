# Rivya Public

Public examples, prompt workflow notes, and integration resources for [Rivya](https://rivya.ai).

Rivya is a multimodal AI workspace for image, video, audio, and chat workflows. This repository is a lightweight public home for examples and external references that should be easy to inspect outside the product UI.

## Useful Links

- Website: https://rivya.ai
- API and developer resources: https://rivya.ai/developers
- Docs: https://rivya.ai/docs
- AI models: https://rivya.ai/ai-models
- Tools: https://rivya.ai/tools

## Repository Scope

This repository may include:

- API integration examples
- Prompt workflow examples
- Public roadmap notes
- Changelog entries for public examples
- Links back to maintained Rivya docs and product pages

This repository does not contain private application code, private credentials, production configuration, or internal provider keys.
