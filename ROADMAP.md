# Public Roadmap Notes

This document tracks conservative public directions for Rivya examples and integration resources. It is not a commitment to ship a specific feature by a specific date.

## Current Focus

- Keep API examples easy to inspect and adapt.
- Keep prompt workflow examples aligned with live Rivya product pages.
- Link developers to the maintained API docs, model reference, and OpenAPI contract.
- Avoid publishing private implementation details, internal provider routing, credentials, customer data, or operational secrets.

## Candidate Additions

- Minimal JavaScript and Python API examples
- Model selection notes that link to Rivya model pages and API model docs
- Files API examples for reference image, video, and audio inputs
- Chat streaming examples that point to the maintained Chat API docs
- Prompt workflow examples for product launch, social content, localization, and creative review

## Maintenance Rules

- Prefer small examples over copied documentation.
- Link to canonical Rivya docs for changing API fields and model availability.
- Keep public wording product-facing; do not expose internal provider or operations language.
