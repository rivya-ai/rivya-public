# Public Roadmap Notes

This document tracks conservative public directions for Rivya examples and integration resources. It is not a commitment to ship a specific feature by a specific date.

## Current Focus

- Keep API examples easy to inspect and adapt.
- Add prompt workflow examples that connect back to maintained Rivya docs.
- Keep links and descriptions aligned with the live product.
- Avoid publishing private implementation details, internal provider routing, credentials, or operational secrets.

## Candidate Additions

- Minimal API request examples
- Prompt workflow examples for image, video, audio, and chat use cases
- Model selection notes that link to Rivya model pages
- Public changelog entries for example updates
